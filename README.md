# NumberToBinary

Программа для перевода целых чисел в двоичный вид.

Она показывает, как обычные числа выглядят в виде последовательности нулей и единиц.

## Пример

Если передать программе число 10, результат будет выглядеть так:

00000000000000000000000000001010

## Как пользоваться программой

1. Откройте свойства проекта.
2. Перейдите в раздел "Отладка".
3. В поле "Аргументы командной строки" укажите нужное целое число.
4. Запустите программу.

## Результат работы

Программа выводит двоичное представление числа в виде 32 символов, состоящих из нулей и единиц.

Это позволяет увидеть, как компьютер хранит целые числа.
